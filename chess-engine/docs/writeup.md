## The hook (why this project)

*Why did you build a chess engine specifically? What about chess interests you from a CS perspective?*

Free chess engines exist but almost none work fully offline — they rely on servers for strong play. I wanted to build one that runs entirely on-device with no network dependency. Every part of the intelligence had to be self-contained: no API calls, no remote evaluation, just local computation. That constraint made the algorithmic efficiency problem (how do you search fast enough on limited hardware?) the central engineering challenge.
